# Kit Currículo Sob Medida

Página responsiva em português do Brasil, feita com React e Vite. A tipografia usa Google Fonts, com fontes locais de fallback quando não houver conexão.

## Executar localmente

Na pasta do projeto, execute:

```sh
npm install
npm run dev
```

Abra o endereço informado pelo terminal (normalmente `http://localhost:5173`). As alterações nos arquivos aparecem automaticamente no navegador.

Para gerar a versão de produção, execute `npm run build`. Os arquivos gerados ficam em `dist/`. Use `npm run preview` para conferir essa versão localmente.

## Arquivos

- `src/App.jsx`: texto completo, seções e constantes de preço e checkout.
- `src/styles.css`: aparência e adaptações para celular.
- `src/main.jsx`: inicialização do React.
- `index.html`: documento de entrada e metadados.
- `vite.config.js`: configuração do Vite.
